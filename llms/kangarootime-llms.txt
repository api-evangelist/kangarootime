# Kangarootime

> Cloud-based childcare and early-education management software for single-site and
> multi-location centers, franchises and after-school programs. Kangarootime publishes
> **no public API** — no REST, GraphQL, SOAP, gRPC, AsyncAPI, webhooks, SDKs or
> developer portal. Its only originating integration surface is **Data Feeds**, a
> configurable daily bulk export of the platform's 63-table dimensional warehouse
> schema to a customer-owned cloud storage bucket. This file was generated by API
> Evangelist from probed public sources; it is not published by Kangarootime.

## Important for agents

- There is no endpoint to call. Do not construct requests against any
  `kangarootime.com` host — no API host exists (`api.`, `developer.` and `docs.`
  subdomains are NXDOMAIN).
- `k2.kangarootime.com` and `insights.kangarootime.com` answer **HTTP 200 to every
  path** with an identical single-page-app shell. A 200 from those hosts is not
  evidence that a resource exists.
- Integration with Kangarootime is configured **inside the application** (Business >
  Integrations), not through a public API.
- The data described below concerns **children, guardians and staff**. Treat any
  Kangarootime-derived dataset as sensitive personal data about minors.

## Data surface (the only machine-readable contract)

- [Kangarootime Data Feed schema reference](https://data-feed.kangarootime.com/): Public table and domain-model reference — 63 tables (36 dimension, 18 fact, 9 bridge) in a Kimball star schema
- [Data Feed User Guide](https://help.kangarootime.com/hc/en-us/articles/45717303390356-Kangarootime-Data-Feed-User-Guide): Destination, path, format and credential configuration
- Destinations: AWS S3, Azure Blob Storage, Google Cloud Storage
- Formats: CSV, JSON/NDJSON, Apache Parquet, XLSX
- Cadence: daily push; **with a blank path the file is overwritten each day**
